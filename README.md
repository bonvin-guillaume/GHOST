# GHOST

Tools and scripts for processing GHOST (auroral) events during PhD research. This repository links event catalogs with multi-instrument data from MISS, SONY, GOA, and BACC cameras at KHO (Kjell Henriksen Observatory), Longyearbyen.

## Overview

The workflow processes a list of GHOST events and finds corresponding data files from multiple instruments:

| Instrument | Data type | Format |
|------------|-----------|--------|
| **MISS-1** | Spectral images | PGM (ASCII) |
| **MISS-2** | Spectral images | PNG |
| **SONY** | All-sky images | Various |
| **GOA** (AllskyGOA) | All-sky images | JPG |
| **BACC** (BACC-LYR) | All-sky video/images | AVI, PNG |

## Requirements

- Python 3.x
- pandas, numpy, matplotlib, scipy, Pillow
- [FFmpeg](https://ffmpeg.org/) (for `BACC_images.py`)

## Workflow

### 1. Process events and find files

```bash
python process_events.py
```

Reads `GHOSTs_events.csv` and searches for corresponding MISS, SONY, GOA, and BACC files based on date and time. Outputs `ghost_df.csv` with file paths and lists.

### 2. Generate MISS spectral plots

```bash
python plot_MISS1.py   # MISS-1 PGM files
python plot_MISS2.py   # MISS-2 PNG files
```

Produces spectral plots in `MISS_plots/` for each MISS file found in the dataframe.

### 3. Extract BACC frames (optional)

```bash
python BACC_images.py
```

Extracts frames at 1 fps from BACC AVI files on the network path. Requires FFmpeg and access to `\\birkeland.unis.no\KHO\BACC\BACC-LYR`.

### 4. Format BACC filenames (optional)

```bash
python format_BACC_filename.py --base-dir <path>        # Dry run
python format_BACC_filename.py --base-dir <path> --execute  # Apply renames
```

Renames BACC frame files by updating timestamps based on the (25, 25, 26) second capture pattern and removing the index suffix.

### 5. Generate interactive HTML table

```bash
python generate_html.py
```

Creates `interactive_GHOST_tool.html` — a browser-based table with clickable links to view MISS spectral plots, SONY, GOA, and BACC images side by side.

## Data paths

Scripts expect access to these network/local paths (edit in each script if your setup differs):

- **MISS-1**: `\\birkeland.unis.no\KHO\MISS-1`
- **MISS-2**: `\\birkeland.unis.no\KHO\MISS-2`
- **SONY**: `\\birkeland.unis.no\KHO\Sony\Quicklooks`
- **GOA**: Local path to AllskyGOA data
- **BACC**: `\\birkeland.unis.no\KHO\BACC\BACC-LYR` (AVI source) and local `BACC_frames/` (extracted PNGs)

## Input files

- **GHOSTs_events.csv** — Event catalog with columns: Date, Start time, Stop time, spectrum time, Comments, etc.
- **ghost_df.csv** — Generated by `process_events.py`; contains file paths and lists per event.

## Scripts

| Script | Description |
|--------|-------------|
| `process_events.py` | Match events to MISS/SONY/GOA/BACC files by date and time |
| `plot_MISS1.py` | Plot MISS-1 PGM spectral files |
| `plot_MISS2.py` | Plot MISS-2 PNG spectral files |
| `BACC_images.py` | Extract frames from BACC AVI files using FFmpeg |
| `format_BACC_filename.py` | Rename BACC frames with correct timestamps |
| `generate_html.py` | Build interactive HTML viewer for events and files |
| `test_plot_MISS-1.py` | Test script for single MISS-1 PGM file |
